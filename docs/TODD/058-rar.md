# 058 — Evaluar rich authorization requests (RAR)

- **Estado:** ausente; opcional. **Prioridad:** baja.
- **Evidencia:** [OidcFlowContext](../../src/Features/OAuth/Authentication/Domain/OidcFlowContext.php) procesa scope/audience básicos, no `authorization_details`; [TokenController](../../src/Features/OAuth/Authentication/Infrastructure/Driver/Rest/TokenController.php) no los conserva.
- **Impacto:** permisos finos no pueden representarse con RFC 9396.
- **Por hacer:** definir tipo de autorización, consentimiento, persistencia en code/refresh y claim autorizado en access token solo si hay requisito.
- **Aceptación:** detalles no aprobados nunca aparecen en token; pruebas por cliente/tenant.
- **Origen:** análisis OAuth §5.4/fase 4.
