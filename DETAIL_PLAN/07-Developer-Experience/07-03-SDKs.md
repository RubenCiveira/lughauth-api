# 07-03 — SDKs Cliente

**Prioridad:** P4  
**Esfuerzo estimado:** Alto (7-10 días)  
**Dependencias previas:** 01-06 OpenAPI completo en endpoints OIDC

---

## Contexto

Sin SDKs, los integradores deben implementar manualmente el protocolo OIDC/OAuth 2.0,
manejar refresh de tokens, PKCE, etc. Los SDKs reducen la fricción de integración
y aseguran que se usen las mejores prácticas de seguridad por defecto.

---

## Qué implementar

### SDK 1: JavaScript/TypeScript (@lughauth/client)

Para aplicaciones web (SPA) y Node.js.

### SDK 2: PHP (lughauth/php-sdk)

Para aplicaciones backend PHP que consumen la Management API o verifican tokens.

### SDK 3: Generación automática desde OpenAPI

Usar `openapi-generator` con la spec de `/management/apidoc` para generar SDKs
en múltiples lenguajes.

### API principal — LughAuthClient

```typescript
interface LughAuthConfig {
  baseUrl: string;       // 'https://auth.example.com'
  tenant: string;        // 'my-tenant'
  clientId: string;
  redirectUri: string;
  scopes?: string[];     // default: ['openid', 'email', 'profile']
  storage?: StorageAdapter;  // default: localStorage
}

class LughAuthClient {
  constructor(config: LughAuthConfig) {}

  /** Inicia el flujo PKCE. Redirige al usuario al IdP. */
  async signIn(options?: { prompt?: 'login' | 'consent'; redirectUri?: string }): Promise<void>

  /** Procesa el callback del authorize flow. Llama desde la página de callback. */
  async handleCallback(): Promise<Session>

  /** Cierra sesión en el IdP y limpia tokens locales. */
  async signOut(options?: { postLogoutRedirectUri?: string }): Promise<void>

  /** Retorna la sesión activa o null. Refresca el token si está expirado. */
  async getSession(): Promise<Session | null>

  /** Retorna el access token (refrescando si necesario). */
  async getAccessToken(): Promise<string | null>

  /** Claims del usuario autenticado (desde id_token o /userinfo). */
  async getUser(): Promise<UserInfo | null>

  /** Verifica si hay una sesión activa. */
  async isAuthenticated(): Promise<boolean>

  /** Suscribirse a cambios de sesión. */
  onSessionChange(callback: (session: Session | null) => void): () => void
}
```

### Manejo automático de PKCE

```typescript
// AuthorizationCodeFlow.ts
async buildAuthorizationUrl(config: AuthUrlOptions): Promise<string> {
  const verifier  = this.generateCodeVerifier();  // 128 bytes random base64url
  const challenge = await this.sha256Base64Url(verifier);

  // Almacenar verifier para el callback
  await this.storage.set('pkce_verifier', verifier);
  await this.storage.set('pkce_state',    this.generateState());

  const params = new URLSearchParams({
    response_type:          'code',
    client_id:              config.clientId,
    redirect_uri:           config.redirectUri,
    scope:                  config.scopes.join(' '),
    state:                  await this.storage.get('pkce_state'),
    code_challenge:         challenge,
    code_challenge_method:  'S256',
    nonce:                  this.generateNonce(),
  });

  return `${config.authorizeEndpoint}?${params.toString()}`;
}
```

### Token Store con auto-refresh

```typescript
// TokenRefresher.ts
class TokenRefresher {
  private refreshTimer: ReturnType<typeof setTimeout> | null = null;

  scheduleRefresh(expiresIn: number, refreshToken: string): void {
    const refreshAt = (expiresIn - 60) * 1000;  // 60s antes de expirar
    this.refreshTimer = setTimeout(() => this.doRefresh(refreshToken), refreshAt);
  }

  private async doRefresh(refreshToken: string): Promise<void> {
    try {
      const tokens = await this.tokenEndpoint.refresh(refreshToken);
      await this.tokenStore.save(tokens);
      this.scheduleRefresh(tokens.expiresIn, tokens.refreshToken);
    } catch {
      await this.tokenStore.clear();
      this.onSessionExpired?.();
    }
  }
}
```

### TokenVerifier — verificar tokens de LughAuth

```php
$verifier = new TokenVerifier(
    baseUrl:  'https://auth.example.com',
    tenant:   'my-tenant',
    cacheDir: '/tmp/lughauth_cache',
);

try {
    $claims = $verifier->verify($accessToken);
    $userId = $claims['sub'];
    $scopes = explode(' ', $claims['scope'] ?? '');
} catch (TokenVerificationException $e) {
    // Token inválido, expirado o revocado
}
```

Internamente:
1. Fetch JWKS desde `GET /openid/{tenant}/jwks` (con cache 1h)
2. Verificar firma RS256 con la clave correspondiente al `kid`
3. Verificar `exp`, `iss`, `aud`
4. Opcionalmente: llamar a `/introspect` para verificar revocación

## SDK generado desde OpenAPI

### Configuración del generador

**Archivo nuevo:** `scripts/generate-sdk.sh`

```bash
#!/bin/bash
# Descargar spec actualizado
SPEC_URL="http://localhost:8080/management/apidoc"
curl -s "$SPEC_URL" > /tmp/lughauth-openapi.json

# Generar cliente TypeScript
docker run --rm \
  -v /tmp/lughauth-openapi.json:/spec.json \
  -v $(pwd)/packages/generated:/output \
  openapitools/openapi-generator-cli generate \
    -i /spec.json \
    -g typescript-fetch \
    -o /output/typescript \
    --additional-properties=npmName=@lughauth/api-client,supportsES6=true

# Generar cliente PHP
docker run --rm \
  -v /tmp/lughauth-openapi.json:/spec.json \
  -v $(pwd)/packages/generated:/output \
  openapitools/openapi-generator-cli generate \
    -i /spec.json \
    -g php \
    -o /output/php \
    --additional-properties=packageName=lughauth/generated-client
```

Añadir a `Makefile`:
```makefile
generate-sdk:
	bash scripts/generate-sdk.sh
```
